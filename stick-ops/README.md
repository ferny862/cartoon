# Stick Ops

A 2D stick-figure shooter styled after modern Call of Duty multiplayer:
6 v 6 Team Deathmatch against bots on a ruined-city map.

Open `index.html` in a desktop browser. No build step or server needed. It is
played with a keyboard and mouse.

## What's in it

- **Loadouts:** M4A1, MP5, KAR98K (scoped) or Model 680 shotgun, plus an X12
  sidearm and two frag grenades you can cook.
- **Movement:** tactical sprint, slide, crouch, jump, and dropping through
  floors.
- **HUD:** minimap with red pings when enemies fire, team score bars and match
  clock, kill feed, ammo counter, hitmarkers (red on kills), damage direction
  arcs, red screen at low health, and a scoreboard on Tab.
- **Killstreaks:** UAV (3 kills), Airstrike (5) and Attack Helo (7). Enemy bots
  earn and call them too.
- **Medals:** First Blood, Headshot, Longshot, Double Kill and more, plus
  level-ups. XP is saved in the browser.
- **Bots:** they move around the map, pick fights at their weapon's best range,
  retreat when wounded, and throw grenades. Three difficulty levels.
- **Audio:** sound effects are generated in the browser, with spoken
  announcements where the browser supports them.

## Controls

| Key | Action |
|---|---|
| A / D | Move |
| W / Space | Jump |
| S | Drop through floor |
| Shift | Sprint |
| C / Ctrl | Crouch (slide while sprinting) |
| Mouse | Aim · left click fire · right click aim down sights |
| R | Reload |
| Q / mouse wheel | Swap weapon |
| G (hold) | Cook and throw frag |
| V / F | Melee |
| 3 / 4 / 5 | UAV · Airstrike · Attack helo |
| Tab | Scoreboard |
| M | Mute |
| Esc | Pause |
